# icondocs (아이콘독스)

Stardock Fences 느낌의 가벼운 바탕화면 아이콘 정리 앱 (Windows 전용, Rust, 외부 런타임 없음).

## 기능
- 바탕화면 파일을 **폴더 / 프로그램 / 문서 및 파일** Fence 로 자동 정리 (최초 실행 또는 트레이 메뉴)
- 새로 생긴 바탕화면 항목은 "새 항목" Fence 로 자동 수집, 삭제된 파일은 자동 제거
- Fence 제목 드래그로 이동, 테두리 드래그로 크기 조절, 제목 더블클릭으로 말아 올리기
- 아이콘 더블클릭 실행, 드래그로 Fence 간 이동/순서 변경, 탐색기에서 파일 드롭
- 우클릭 메뉴: 이름 바꾸기, 색상(5종), 이름순 정렬, Fence 삭제 / 열기, 파일 위치 열기
- 바탕화면 빈 곳 더블클릭 → 모든 Fence 숨기기/보이기
- 트레이 메뉴: 새 Fence, 자동 정리, 원래 바탕화면 아이콘 숨기기 토글, 시작 프로그램 등록, 종료

## 빌드
```
cargo build --release
```
