# icondocs (아이콘독스)

Stardock Fences 느낌의 가벼운 바탕화면 아이콘 정리 앱 (Windows 전용, Rust, 외부 런타임 없음, 실행 파일 약 370KB).

## 기능
### 정리
- 바탕화면 파일을 **폴더 / 프로그램 / 문서 및 파일** Fence 로 자동 정리 (최초 실행 또는 트레이 메뉴)
- **규칙 기반 자동 분류**: `*.pdf;*.docx`, `<dir>` 같은 패턴으로 새 파일을 지정 Fence 에 자동 배치.
  아이콘 우클릭 → "이 종류를 … 로 자동 분류" 로 한 번에 규칙 추가. 규칙에 안 맞는 파일은 "새 항목" Fence 로.
- **폴더 포털**: 다운로드·문서 등 임의 폴더 내용을 Fence 안에 표시. 폴더 더블클릭으로 하위 탐색, 제목 왼쪽 `‹` 또는 Backspace 로 상위로.
  탐색기에서 파일을 드롭하면 그 폴더로 **이동**됩니다.
- 삭제된 파일은 자동 제거, 새 파일은 자동 수집

### Fence 조작
- 제목 드래그 이동, 테두리 크기 조절, 제목 더블클릭 **말아 올리기** (마우스를 올리면 임시로 펼침)
- 바탕화면 빈 곳을 **드래그하면 새 Fence** 생성, 빈 곳 **더블클릭**으로 모든 Fence 숨김/표시
- 우클릭 메뉴: 이름 바꾸기(F2), 아이콘 크기(16/32/48px), 투명도, 색상, 제목 표시줄 숨기기, 잠금, 이름순 정렬, 삭제
- 아이콘: 더블클릭 실행, **Ctrl/Shift 다중 선택**, 드래그로 Fence 간 이동·순서 변경, 탐색기 드롭(바탕화면 밖의 파일·폴더는 바탕화면에 **바로 가기**를 만들어 추가)
- 키보드(바탕화면이 활성일 때): Enter 실행, Delete 제거, F2 이름 바꾸기, Ctrl+A 전체 선택, 방향키 이동, Esc 선택 해제

### 피크 / 핫키 / 레이아웃
- **피크**: 다른 창 위로 모든 Fence 를 즉시 끌어올림. 트레이 아이콘 클릭, 핫코너(기본 오른쪽 위), 또는 `Ctrl+Shift+P`. Esc 나 바깥 클릭으로 종료
- `Ctrl+Shift+F` 모든 Fence 숨김/표시 (단축키는 `layout.txt` 의 `hotkey_toggle=`, `hotkey_peek=` 로 변경, 예: `ctrl+alt+F9`)
- **바탕화면 검색**: `Win+Space`(또는 트레이 메뉴)로 화면 중앙에 검색창. 바탕화면의 앱·바로 가기·파일·폴더를 이름으로 찾고 **Enter 로 첫 항목 실행**.
  ↑/↓ 로 선택, 클릭으로 실행, Esc·바깥 클릭으로 닫기. 여러 단어(`vis code`)와 한글 초성(`ㅋㅋㅇ` → 카카오톡) 검색 지원.
  이름이 검색어로 시작하는 항목 → 단어 시작 → 중간 일치 순이며, 같은 순위면 바로 가기·실행 파일이 먼저.
  **실행 중인 창**은 "창 제목 - 프로그램 이름"(예: `작업장 - Visual Studio`)으로 나와 프로그램 이름으로도 찾을 수 있고, 선택하면 그 창으로 전환한다(최소화돼 있으면 복원).
  검색어가 없을 때는 실행 중인 창 목록이 바로 보여 ↑/↓ 로 고를 수 있다(방금 쓰던 창이 맨 위). 같은 순위면 바로 가기 → 실행 중인 창 → 파일 순.
  Windows 의 입력 언어 전환(Win+Space)을 대신하므로, 다른 키를 쓰려면 `hotkey_search=` 로 변경(예: `alt+space`)
- **레이아웃 스냅샷**: 트레이 → 레이아웃 → 현재 배치 저장/복원/삭제. 해상도가 바뀌면 이전 해상도 배치를 자동 저장하고, 새 해상도용 배치가 있으면 자동 복원
- 트레이 메뉴: 새 Fence, 폴더 포털, 자동 정리, 규칙 다시 적용, 원본 아이콘 숨기기, 시작 프로그램 등록, 종료

## 설정 파일
`%APPDATA%\IconDocs\layout.txt` (key=value 텍스트), 스냅샷은 `%APPDATA%\IconDocs\snapshots\*.txt`.
